# Pandas for Real-World Data — free course by TechTZ Academy

Notebooks and data for the 10-lesson YouTube course:
▶️ https://www.youtube.com/playlist?list=PLMku34AeSreg

All examples use realistic business data from **Duka Bora**, a fictional electronics shop with four branches in Tanzania (Kariakoo, Mlimani City, Arusha CBD, Mwanza Rock City).

| # | Lesson | Notebook |
|---|---|---|
| 1 | What is pandas? Series & DataFrames | `lesson01.ipynb` |
| 2 | Loading & inspecting real data | `lesson02.ipynb` |
| 3 | Selecting & filtering | `lesson03.ipynb` |
| 4 | Cleaning messy data | `lesson04.ipynb` |
| 5 | New columns & transformations | `lesson05.ipynb` |
| 6 | groupby & aggregation | `lesson06.ipynb` |
| 7 | merge & concat (mobile-money reconciliation) | `lesson07.ipynb` |
| 8 | Dates & time series | `lesson08.ipynb` |
| 9 | Charts & Excel reports | `lesson09.ipynb` |
| 10 | Final project: 2025 business review | `lesson10.ipynb` |

## Data (`data/`)
- `orders.csv` — 2,400 orders in 2025
- `orders_messy.csv` — a messy export for the cleaning lesson
- `products.csv` — 12 products with price and cost
- `customers.csv` — 300 customers
- `mobile_money.csv` — M-Pesa, Tigo Pesa, Airtel Money and HaloPesa payment records

## How to run
1. Install Python 3.10+ and run `pip install pandas numpy matplotlib openpyxl jupyter`
2. Download this repo (green **Code** button → **Download ZIP**) and unzip it
3. In the folder, run `jupyter notebook` and open `lesson01.ipynb`

Or open any notebook in Google Colab and upload the `data` folder.
